Interactive simulator

Same intent. Same outcome. Rules change live.

Maria, a support agent, asks: "Refund order #4821, the item arrived broken." Flip the four safety switches, choose where each rule is set (whole company, team, or just Maria), pick a "what could go wrong" situation, and run it. The request and the workflow never change. Only the protection around them does. No rebuild, no redeploy.

Think of it like kids: AI agents and tools (MCPs) are fast, eager helpers, but you don't hand them the car keys. Identity = who they may talk to. Knowledge = which books they may read. Guardrails = things they must never do. Governance = when a grown-up must say yes. Parents can change the house rules any time without rebuilding the house.

What happens in this run?

Every situation uses the same request from Maria. Some add a twist, like an attacker or a risky ask, so you can see which switch saves the day.

The four switches

Turn each one on or off and choose who sets it. Changes apply on the very next request.

Maria's final rule book

Before every request, Company → Team → Maria rules are merged into one set. Locked company rules always win, "no" beats "yes", and the strictest limit wins.
