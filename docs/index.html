The shortest useful explanation

What happens after someone asks ContextWeaver to do something?

ContextWeaver selects a published ServiceThe user's intent resolves to an immutable Service and exact Workflow versions. The complete execution graph is authorizedIdentity, entitlements, Agents, MCPs, tools, data, models, budgets, and fallbacks are checked. The run is accepted durablyState and outbox records commit before the request ends, so work does not belong to one browser or pod. Workers execute typed nodesAgents, MCP tools, models, RAG, approvals, and verification exchange governed artifacts. Authority is checked again before actionAgents never receive raw credentials, and side effects require current authorization. The result includes proofCitations, decisions, revisions, attempts, receipts, metrics, logs, and traces remain available for review.
