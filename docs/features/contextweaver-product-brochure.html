The product thesis

The model is not the platform.

The platform is the system that makes models, tools, data, automation, and human accountability work together safely.

1Specify everythingEvery Service, Workflow, Agent, MCP tool, schema, model alias, dashboard, alert, and compensation behavior is versioned and machine-validatable.
2Admit dynamicallyTeams can onboard capabilities through the UI, but deployment occurs only after compatibility, supply-chain, security, evaluation, approval, and operational gates pass.
3Compose safelyThe registry discovers only compatible and authorized capabilities, and the compiler freezes them into an immutable execution plan.
4Operate continuouslyReliability, quality, groundedness, safety, policy, cost, freshness, citations, and rollback are measured throughout the lifecycle.
ContextWeaver keeps the creativity of AI dynamic, while making its authority, data, side effects, evidence, and failure behavior deterministic.

Security and compliance by construction

Agents and tools receive constrained capabilities, not ambient authority.

Compliance profiles vary by vertical, but the enforcement architecture stays consistent.

Identity everywhereHuman and workload identity, tenant, purpose, delegation chain, correlation ID, and policy version accompany every protected operation.
Hostile-code sandboxNon-root, read-only root, no privilege escalation, all capabilities dropped, seccomp, bounded resources, disposable pods, and signed images.
Stronger runtime isolationgVisor or Kata RuntimeClass and dedicated tainted node pools for code-executing, third-party, regulated, or higher-risk Agents.
Default-deny networkNo general internet, cloud metadata, Kubernetes API, host socket, developer endpoint, or cross-domain MCP access.
RabbitMQ capability boundaryTyped asynchronous messages, least-privilege exchanges and queues, TLS, publisher confirms, manual acknowledgements, DLQ, TTL, and rate controls.
Only one inference boundaryThe Model Gateway enforces approved models, regions, classifications, redaction, token/cost limits, DLP, and provider policy without sharing credentials.
Separate MCP sandboxesEach MCP reaches only its approved plugin or external-system domain; an Agent never directly opens a tool endpoint.
Outputs remain untrusted dataAgent-authored content is schema-validated, policy-projected, hashed, and stored as immutable data - never automatically executed by an IDE, shell, build tool, or host.
Credential non-possessionAgents receive only narrow workload identity and opaque references. Trusted gateways resolve short-lived credentials just in time and never return them to the Agent.
Continuous entitlement enforcementWhole-graph preflight authorizes the immutable plan before a run begins. Every protected node and MCP tool is reauthorized at use time with a short-lived plan/run/node/tool-bound capability token.
Cross-pod work recoveryPostgreSQL state, RabbitMQ redelivery, renewable leases, checkpoints, inbox/outbox, idempotency, and receipts allow another replica to safely resume failed work.
Operator-owned deploymentAgents and MCPs deploy only from signed, scanned release bundles through allowlisted Helm packages. Runtime discovery registers schemas, tools, health, metrics, dashboards, alerts, and evidence before promotion.
Compliance approach: ContextWeaver supplies the technical control plane and evidence model. Healthcare, banking, government, and other regulated deployments add their authoritative legal interpretation, risk acceptance, vendor agreements, retention schedules, control mappings, and human accountability.

Current product foundation and direction

Built incrementally, without overstating completeness.

Implemented locally

  • Cloud-neutral repository, image, Helm, GitOps, namespace, and pipeline architecture as the sole target architecture.
  • Registry service with immutable registration, AI provider configuration, logical alias resolution, and multi-service release compatibility validation.
  • Source Catalog and Freshness Ledger with ownership, authority, revision, ACL, lifecycle, PostgreSQL persistence, and immediate stale/revoked/deleted blocking.
  • Version-pinned RAG ingestion, local extraction/chunking, shadow generations, validation gates, atomic publication, rollback, governed lexical/vector retrieval, and citations.
  • Durable Service and Workflow Runs with RabbitMQ dispatch, human approvals, timers, event waits, callbacks, notification, publication, verification, finalization, and correlated observability.
  • Services Studio, Run History, Approval Inbox, Registry-discovered Agents and MCPs, workspaces, local container environment, tests, publications, and editable architecture.

Product realization roadmap

  • Complete production policy, entitlement, audit, artifact, credential-exchange, and capability-token enforcement.
  • Add production storage events, reconciliation, malware/DLP/poisoning scanners, richer extraction, managed embeddings/reranking, distributed deletion, and scale qualification.
  • Deliver dynamic Agent and MCP admission, independent sandboxed runtimes, operator reconciliation, model-gateway enforcement, canarying, and continuous evaluations.
  • Operationalize dashboard and alert specifications, privacy-safe telemetry, release promotion, multi-region recovery, vertical policy packs, and end-to-end compliance evidence.
