Hierarchical Scope Model

Cascade Hierarchy
User Scope
Personal credentials, preferences, limits. Highest priority.
↓
Group Scope
Team-level policies, shared credentials, budget pools.
↓
Org Scope
Global rules, compliance, default credentials. Lowest priority.
Resolution Rules
Credentials — First-found-wins
Check User → Group → Org. Use the first match. No merging.
RAG Policies — All-tiers-merge
Collect policies from User + Group + Org. Union of all rules applies.
