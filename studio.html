What can be created

Four reusable runtime artifact types—and the Solution that composes them.

The Studio makes each responsibility explicit: an MCP is not an Agent, a Workflow is not a Service, and a reusable Service is not the complete user-facing Solution.

MCP capability

The governed tool boundary

Exposes tools, resources, and prompts with typed schemas, delegated identity, side-effect classes, receipts, idempotency, and compensation metadata.

Agent

The bounded reasoning specialist

Uses an approved model, knowledge, instructions, budgets, and MCP allow-list to produce a typed result for one defined responsibility.

Workflow

The durable coordination graph

Orders Agent and capability work through typed steps, branches, parallel joins, waits, approvals, callbacks, retries, checkpoints, and compensation.

Service

The reusable executable contract

Publishes a stable intent-to-outcome contract pinned to one or more approved Workflows, with inputs, outputs, policies, SLOs, and lifecycle.

Solution

The final user-facing composition

Packages the complete dependency graph, experience contract, presentation, lifecycle, and one or more Services into what a consumer actually discovers and uses.
