Google Cloud mapping

Equivalent managed services beneath Kubernetes contracts

The provider mapping must satisfy the same data, identity, availability, recovery, and governance evidence gates.

IdentityCloud Identity or approved external OIDC for users; Workload Identity Federation for Kubernetes workloads.
ComputePrivate GKE with isolated node pools for system, control, execution, RAG, gateway, and capability workloads.
Durable stateCloud SQL for PostgreSQL or AlloyDB after compatibility validation, with HA, backups, PITR, pgvector, and failover tests.
MessagingRabbitMQ quorum queues on GKE or a validated compatible managed topology; Pub/Sub is not substituted without preserving ordering, acknowledgement, redelivery, and transaction semantics.
ArtifactsCloud Storage with versioning, encryption, retention, tenant boundaries, object immutability, and lifecycle controls.
SecretsOpenBao/Vault as portable broker, optionally integrated with Secret Manager, Cloud KMS, and External Secrets.
ModelsVertex AI or approved external providers behind the same Model Gateway policy, redaction, region, budget, and evidence contracts.
SearchPostgreSQL full-text search plus pgvector initially; a distributed search service is added only after measured need.
EdgeCloud Load Balancing, Cloud Armor, API Gateway or a supported Kubernetes gateway, and private service connectivity.
OperationsPrometheus, Grafana, Loki, OpenTelemetry, Cloud Operations integration, immutable audit, SLOs, and recovery exercises.
Non-negotiable invariants

Portability preserves behavior, not just component names

PostgreSQL owns truth

Run state, tasks, leases, timers, HITL, inbox/outbox, checkpoints, receipts, and Saga state remain durable.

RabbitMQ owns dispatch

Agent, MCP-intent, RAG, workflow, and runtime commands/events are queue-mediated and recoverable.

Gateways own provider access

Agents do not directly reach MCPs, databases, object stores, Kubernetes APIs, cloud metadata, or the internet.

Plans own authorization scope

Request-time preflight freezes authority; runtime policy revalidates every protected action.

Operators own deployment

Only approved, scanned, signed Agent and MCP Helm releases become discoverable capabilities.

Evidence owns promotion

Compatibility, security, quality, SLO, rollback, and recovery evidence gates every release.
